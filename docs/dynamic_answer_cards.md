# 动态答题卡

进入 **答题卡工具**，或在识别模板列表点击 **调整题型 / 预览**。

- 默认采用第十六届软件方向 A/B/C 的两页、64 题组合，也可套用第十五届 A 卷版式。
- 学号支持 6—12 位。姓名、手写学号与卷型栏均可单独开关。
- 题型支持单选、多选、判断、填空、逻辑改错、材料问答、解答 / 算法题。
- 每个区块可设题数、标题、选项数或作答行数、子空数，并支持复制、删除、上下移动。
- 单张答题卡限制为 300 题、24 个区块、24 页；调整后自动连续编号和分页。
- 修改后约 300 毫秒请求最新预览。预览直接渲染最终 PDF；旧请求结果会被丢弃。
- 配置保存在当前浏览器；工作区启用时按工作区隔离。切换参考版式或恢复参考版式会重新加载对应组合。
- 点击 **生成 PDF 与扫描配置** 下载 A4 PDF 和配置包。

## 扫描配置

每页的 `template.json`、`reference_blank.png`、`config.json` 位于 `pages/page_N/`。
根目录配置对应第一页。请将同一页的扫描图与对应页配置配套使用。
`layout.json` 保存题型、页码、连续题号与作答区域；`manifest.json` 列出逐页资源。
设计器生成的题号与现有固定考试模板分别维护，导出后按相应版式使用扫描配置。

## 服务端接口

- `GET /api/sheets/presets`：读取预设和限制。
- `POST /api/sheets/preview`：根据 `sections`、`id_digits` 和身份栏选项生成逐页 SVG 预览。
- `POST /api/sheets`：生成 PDF 与逐页扫描配置包。

工作区模式使用 `/w/{workspace_id}` 路径前缀；网页自动添加该前缀。
旧版客户端的 `mcq_count`、`tf_count`、`text_count` 参数保留原有单页生成路径。
