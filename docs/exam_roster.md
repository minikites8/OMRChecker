# 每场考试的考生名单与缺考核对

## 使用步骤

1. 在「试卷管理」导入考试，随后进入「考生管理」。
2. 在「考试名单与缺考核对」选择考试，点击「导入 / 更新考生名单」。
3. 点击「下载录入模板」保存 `考生名单录入模板.csv`。模板自带「学号」「姓名」两列表头，从第二行开始填写，保存后上传导入。也可直接上传 CSV / TSV 文件，或从 Excel 复制含表头的两列并粘贴。
4. 名单表头为「学号」「姓名」。学号支持 6—12 位完整数字，Excel 中将学号列设为文本以保留前导零。
5. 上传答题卡后，系统按本场考试的学号匹配名单。使用「缺考」筛选查看名单，点击「导出缺考名单」保存 CSV。

CSV 示例：

```csv
学号,姓名
000001,张三
000002,李四
```

支持 UTF-8（含 BOM）和 GB18030 编码，单文件最大 2 MB，每场最多 10000 人。重复学号、缺失姓名和学号格式异常会返回对应校验信息，原名单继续生效。

## 匹配与出勤规则

- 考试使用 `import_id` 关联名单，各工作区分别保存。
- 匹配键为完整学号，保留前导零。同名考生按各自学号核对。
- 匹配成功后，考生列表、答卷复核、批次结果和成绩导出均采用名单原始姓名。
- 原始 AI / 人工姓名与 OCR 结果继续保存在答卷记录中，便于追溯。名单姓名通过展示层动态应用。
- 名单内至少有一份答卷的学号计为「已交卷」，多份答卷计为一名考生，并在「重复答卷」筛选中提示。
- 名单内暂时没有匹配答卷的考生显示「缺考」。该结果随已上传答卷变化，请在完成上传并核对异常学号后确认。
- 学号含 `?`、空学号和名单外学号单独列出，便于人工核对。保存学号更正后自动更新名单姓名与出勤。
- 重新导入将完整替换本场名单，原答卷、成绩和原始识别结果保持原样。

## 接口与存储

- `GET /api/exam/roster?import_id=...`：本场名单、逐人出勤、重复答卷和名单外答卷。
- `POST /api/exam/roster`：传入 `import_id` 与 `content` 文本，或 `file: {name, data}`（Base64 / data URL）上传文件。
- 文件保存于考试目录的 `candidate_roster.json`，先完整校验，再原子替换；启用 COS 时使用本场考试的存储键同步。
- 标准库 HTTP 服务与 FastAPI 后端均支持这两个接口，并沿用当前工作区访问控制。
