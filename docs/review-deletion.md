# 删除批改记录及考生信息

工作台的最近批改、成绩与复核、考生管理均提供删除入口。确认框列出关联影响；服务端删除该答卷的批改结果、考生信息、扫描文件，并清理最近记录与批量记录中的关联项。试卷导入库和同一考生的其他答卷继续保留。

- API：`POST /api/review/delete`，兼容入口 `POST /api/candidates/delete`；JSON 请求为 `{"review_id":"批改编号"}`。
- 登录环境按记录归属校验，管理员可管理全部记录；运行中的 AI、姓名识别与批量任务返回 409。
- 本地记录先移至服务目录之外的临时清理目录，索引更新失败时恢复；清理失败返回 503，可用同一编号重试。云端模式按 `review/<review_id>/` 前缀清理 COS 当前对象及数据库索引。
- 旧版共享 COS 路径继续按共享对象保留；新写入的复核资源采用独立批改编号前缀。
